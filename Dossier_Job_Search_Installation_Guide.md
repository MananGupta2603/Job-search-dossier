# Dossier Automate Job Search Installation Guide
## Windows 11 + Docker Desktop + Ollama + Qwen 2.5:3b

**Purpose:** Reference guide for installing or restoring Dossier with a locally running AI model on Windows.

---

## 1. System requirements

The setup used these specifications:

| Component | Details |
|---|---|
| Operating system | Windows |
| Terminal | PowerShell |
| CPU | Intel Core i7-12650H |
| RAM | 16 GB |
| Container platform | Docker Desktop |
| AI model | Qwen 2.5 7B |
| Application | Dossier |

## 2. Install Docker Desktop

1. Download Docker Desktop from https://www.docker.com/products/docker-desktop/
2. Install Docker Desktop.
3. Start Docker Desktop.
4. Open PowerShell and verify:

```powershell
docker --version
docker compose version
```

Docker Desktop must be running before using the following commands.

## 3. Create the Dossier directory

```powershell
mkdir C:\dossier
cd C:\dossier
```

## 4. Download the Dossier Compose file

```powershell
curl.exe -fsSL -o compose.yml https://raw.githubusercontent.com/AienTech/dossier/main/compose.production.yml
```

This downloads the Docker Compose configuration required to run Dossier.

## 5. Configure environment variables

Create an `.env` file in `C:\dossier`.

It must contain these three variables:

```env
POSTGRES_PASSWORD=YOUR_POSTGRES_PASSWORD
DOSSIER_SECRET=YOUR_DOSSIER_SECRET
DOSSIER_PASSWORD=YOUR_DOSSIER_PASSWORD_HASH
```

**Important:**

- `POSTGRES_PASSWORD`: Use a securely generated hexadecimal password to avoid database URL encoding problems.
- `DOSSIER_SECRET`: Generate a secure random secret.
- `DOSSIER_PASSWORD`: Use the password hash generated by Dossier's hash-password command.

Generate a PostgreSQL password using PowerShell:

```powershell
$bytes = New-Object byte[] 24
$rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$rng.GetBytes($bytes)
$rng.Dispose()
$postgresPassword = ([BitConverter]::ToString($bytes)).Replace("-", "").ToLowerInvariant()
```

Generate a Dossier secret:

```powershell
$bytes = New-Object byte[] 32
$rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$rng.GetBytes($bytes)
$dossierSecret = [Convert]::ToBase64String($bytes)
$rng.Dispose()
```

Generate the Dossier password hash:

```powershell
docker run --rm -it --platform linux/amd64 ghcr.io/aientech/dossier hash-password
```

Follow the prompts and copy the complete output into `DOSSIER_PASSWORD`.

The generated hash format in this installation was:

```text
argon2id:m=19456,t=2,p=1:SALT:HASH
```

Use the exact output generated by the command, not this example.

## 6. Start Dossier

From `C:\dossier`, run:

```powershell
docker compose up -d
```

Check the containers:

```powershell
docker compose ps
```

Expected services:

- `app` – Dossier application
- `db` – PostgreSQL database

Open Dossier:

http://localhost:3000

## 7. Enable Ollama in Docker

To run Ollama alongside Dossier, enable the AI Compose profile.

First, check whether the profile already exists:

```powershell
Select-String -Path .env -Pattern '^COMPOSE_PROFILES='
```

If there is no output, add:

```powershell
Add-Content -Path .env -Value "COMPOSE_PROFILES=ai"
```

If a profile already exists, update that line to include `ai` while preserving any other existing profiles.

Start the services:

```powershell
docker compose up -d
```

Verify:

```powershell
docker compose ps
```

Expected services:

- `app`
- `db`
- `ollama`

Do not delete existing containers or database volumes to enable Ollama.

## 8. Download the Qwen AI model

Download Qwen 2.5:3b:

```powershell
docker compose exec ollama ollama pull qwen2.5:3b
```

The model download is approximately 4.7 GB.

Verify the downloaded model:

```powershell
docker compose exec ollama ollama list
```

Expected model:

```text
qwen2.5:3b
```

## 9. Connect Ollama to Dossier

Open Dossier:

http://localhost:3000

Navigate to:

**Settings → AI provider → Local model (Ollama or llama.cpp)**

Use these settings:

| Setting | Value |
|---|---|
| Provider | Local model |
| Server address | `http://ollama:11434` |
| Model | `qwen2.5:3b` |
| API key | Leave empty |

Click **Test connection**.

A successful connection confirms that Dossier can communicate with Ollama.

**Important:** Use `http://ollama:11434`, not `http://localhost:11434`. Both services communicate through Docker's internal network.

## 10. Useful Docker commands

| Task | Command |
|---|---|
| Start services | `docker compose up -d` |
| Stop services | `docker compose stop` |
| Restart services | `docker compose restart` |
| Check status | `docker compose ps` |
| View application logs | `docker compose logs -f app` |
| View database logs | `docker compose logs -f db` |
| View Ollama logs | `docker compose logs -f ollama` |
| List AI models | `docker compose exec ollama ollama list` |

Open Dossier at:

http://localhost:3000

## 11. Important precautions

1. Always start Docker Desktop before using Dossier.
2. Keep the `C:\dossier` directory and `.env` file safe.
3. Never share your `.env` file or its secrets.
4. Back up your database and configuration before making major changes.
5. Do not run `docker compose down -v` casually. It removes Compose-managed volumes and can delete your database data.
6. Do not delete the Ollama model volume if you want to retain downloaded models.
7. Qwen 2.5 7B requires substantial memory. Performance will depend on available RAM and GPU resources.
